# پروژه اندروید اپلیکیشن آرام جان (Aram Jan Android App)

این پروژه پیاده‌سازی کامل و نیتیو اپلیکیشن **آرام جان** بر اساس طرح فیگما با استفاده از جدیدترین تکنولوژی‌های اندروید (**Kotlin** و **Jetpack Compose**) است.

---

## 🚀 روش ساخت فایل APK با GitHub Actions (بدون نیاز به اندروید استودیو):
۱. در سایت GitHub.com یک حساب رایگان بسازید.
۲. یک Repository جدید به نام `AramJan` ایجاد کنید.
۳. تمام محتویات پوشه `AramJanApp` را در آن آپلود کنید.
۴. به تب **Actions** بروید و روی **Run Workflow** کلیک کنید.
۵. پس از ۲ دقیقه، فایل `app-debug.apk` آماده دانلود بر روی گوشی شماست!
